Tech Stack

Modern, schnell,
vollständig serverless.

React + Vite + TypeScript
FastAPI (Python)
Supabase (PostgreSQL)
Google Gemini 2.5 Flash
Vercel (Frontend + API)
MUI + eigenes Dark Theme
  • KI-Fördermatching via Gemini Reasoning
  • PDF-Texterkennung + Bildanalyse
